== 4. Review (Astra, CHANGES): iOS's notification settings path ==

Section 1 above first called "Settings → Rehearsly → Notifications" checked and
true. It was not checked against a source, and it is wrong on current iOS:
since iOS 18 an app is no longer a row of Settings itself but sits under
Settings → Apps, so a person following the page does not find Rehearsly there.
Apple's guide (support.apple.com, "Change notification settings on iPhone")
gives Settings → Notifications → the app, a list that holds on every iOS
version. All four languages now say it in Apple's words: Settings →
Notifications → Rehearsly / Настройки → Уведомления → Rehearsly / Ajustes →
Notificaciones → Rehearsly / Einstellungen → Mitteilungen → Rehearsly. The page
has no other iOS Settings path (calendar access is not described as a path).

supportPage.test.js, new per language: the section contains
"<Settings> → <Notifications> → Rehearsly" in Apple's words and not
"<Settings> → Rehearsly".
