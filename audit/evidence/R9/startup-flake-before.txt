The root of date-fns-tz loads format/formatters -> _lib/tzIntlTimeZoneName,
which does `import { getDefaultOptions } from 'date-fns'`: the whole date-fns
barrel (every function and locale index) for one getter. utils/timezone.js
imports the root of date-fns-tz but uses only fromZonedTime. So about half of a
server's cold import is a library barrel it never uses, and under load that
alone exceeds the fixture's start wait.
