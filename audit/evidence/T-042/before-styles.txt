T-042 — StyleSheet keys BEFORE, source commit c191807.

knip does not look inside StyleSheet.create, and ESLint's react-native/no-unused-styles
only sees a style object used in the file that declares it (it reports 0 here: most
screens import theirs from features/*/styles/*.ts). So the tool is the TypeScript
language service: for each key of each StyleSheet.create({...}) in src/ (tests
excluded), findReferences over the whole tsconfig program (src, tests, App.tsx,
index.ts). Script: unused-styles.mjs next to this file.
