## Where the code differs from the note — written by the code

- **503 on login.** Three answers are a 503 on `/admin/api/login`: adminAuth.js's
  `Admin panel not configured`, `requireDatabase`'s `Service temporarily
  unavailable` (app.js) and the rate limiter's store failure `Authentication is
  temporarily unavailable` (operationIpRateLimit.js). «Вход не настроен…» would be
  false for the last two, so the page reads the answer's `error` (never shows it)
  and says «Вход не настроен: … (ADMIN_PASSWORD_HASH или ADMIN_PASSWORD).» only
  for the first; any other 503 is «Не удалось войти. Попробуйте ещё раз.»
  (section 3, «Любая другая ошибка»).
- **⍽ before a dash** is put in the notes, as decided («в сносках»); the steps
  cell («владелец — 1») and the stale notes keep ordinary spaces.
- **Empty field** is answered before any request («Введите пароль.»), and a 400
  gives the same words, as section 3 says.
- Login answered 200 without a token, or with a body that is not JSON:
  «Сервер ответил не так, как ожидалось. Попробуйте ещё раз.»
