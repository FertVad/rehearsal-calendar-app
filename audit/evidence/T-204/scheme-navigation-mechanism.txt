Probes: scheme-navigation-probe{1,2,3}.mjs and scheme-navigation-probe-timers.mjs
in this directory. To rerun, copy one
to rehearsal-calendar-native/server/__tests__/browser/ and run `node <file>`.

2. The paused clock still runs zero-delay timers, so the page's first attempt
   (setTimeout(..., 0) in invite.js) starts at a moment the test does not
   control. scheme-navigation-probe-timers.mjs (page script replaced by three

   an error. clock.runFor -> safeNonStallingEvaluateInAllFrames ->
   raceAgainstEvaluationStallingEvents throws "Frame is currently attempting a
   navigation" when the frame has a pending document, and
   safeNonStallingEvaluateInAllFrames swallows it. probe1, 80 runs without
   ?expoHost, 5 failed, all like this one:

     run 32: FAIL locator.click: Timeout 5000ms exceeded.
       311ms goto resolved, page clock 2026-09-18T12:00:01.000Z

       325ms requestfailed rehearsalapp://invite/ABCDEFGH net::ERR_ABORTED
       329ms runFor resolved, page clock 2026-09-18T12:00:01.000Z

   runFor(3000) resolved but the page clock did not move, the fallback never
   appeared, and the click waited 5 s for a visible #openButton — the
   "locator.click … element is not visible" failures (Expo links, untrusted
   codes, manual activation). With ?expoHost: 3 of 60 runs, same picture.
