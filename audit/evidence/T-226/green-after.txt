The fix (e2e/run.mjs, e2e/junit.mjs, docs/e2e.md "A run past midnight"):
Maestro gets the flows in batches that end before the machine's midnight (as
many as fit at 10 minutes a flow in b463ff3, 5 in b1e2692; when none fits,
the run waits for midnight, in b1e2692 only if the wait fits the
supervisor's limit). Before each batch the day is compared with the seed's; a day that
turned gets a new database in the same container, the server restarted on it
and the seed made again. Far from midnight the whole set is still one Maestro.
