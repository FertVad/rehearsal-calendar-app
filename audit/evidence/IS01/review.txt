The review found and resolved a worktree path race. Originally realpath checked
ancestry before lstat/open; replacing a directory with an outside symlink in
that interval let both lstat and open accept the same outside inode. The repair
captures the expected inode before path validation, compares the opened file to
that inode, and revalidates ancestry and current path identity before reading.
The new CLI regression performs a deterministic synthetic filesystem mutation
and separately observes reads of the outside inode. It requires the mutation
barrier to fire, outsideReadAttempts=0 and exit 2; failure after reading does not
satisfy the test.

The worktree guarantee is deliberately bounded: identity/path checks detect
common replacements, but Node path APIs do not supply an atomic filesystem
snapshot or complete protection against a hostile process rearranging the
filesystem concurrently. README states this limit and directs commit checking
to immutable staged blobs. This is not an openat-equivalent guarantee.
