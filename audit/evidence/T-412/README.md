## Что сделано

- `OnboardingStep`: вверху «‹ Назад» (`onboarding-back`, кнопка с подписью,
  44 pt, как «Пропустить»; на приветствии нет) и «Пропустить»; внизу
  (`onboarding-footer`) — фиолетовый ответ, под ним серый, под ними сноска.
  Ни «Далее», ни ответа в содержимом. Пропсы `answer` / `secondAnswer`
  заменили `onNext` / `nextButtonTitle` / `secondaryAction` / `showBackButton`.
- Шаги: выходные (обе кнопки недоступны во время сохранения), календарь
  («Разрешить доступ» внизу над «Настроить позже»; выбранный календарь —
  ответ: галочка 0,5 с, затем «Уведомления»; провайдер с несколькими
  календарями только раскрывает список; при возврате подключённый отмечен,
  тап по нему — дальше без повторного подключения, по другому — подключение
  и дальше), уведомления («Включить» над «Не сейчас»), «Что где» и
  приветствие — одна фиолетовая «Начать».
- Тексты — из заметки; `onboarding.next` и `onboarding.calendarSync.next`
  удалены во всех языках. Заголовок шага календаря — «Синхронизация
  календаря» / «Calendar Sync» / «Sincronización del⍽calendario» /
  «Kalender-Sync», до двух строк. Вопрос про выходные — три строки, дни
  своей строкой.
- Набор: `shared/utils/typeset.ts` — правило раздела 2 заметки, одно на все
  тексты онбординга; `StepText` применяет его и `lineBreakStrategyIOS
  ="push-out"` (заголовок, описание, сноски, строки «Что где», примеры
  уведомлений, преимущества приветствия, тексты карточки календаря); подписи
  ответов тоже через `typeset`. Путь в сноске календаря — через `settingPath`.
- Вопрос из нескольких строк: 32 pt, уменьшается на 1 pt, пока iOS
  раскладывает его больше чем в свои строки, не ниже 26 pt, и не обрезается.
  Первый вариант (`numberOfLines 3` + `adjustsFontSizeToFit`) на телефоне не
  уменьшал вопрос: строки переносились внутри, последняя («как занятые?»)
  обрезалась — видно на снимке первого прогона, поймано по скриншотам и
  исправлено во втором коммите.
- Шаги онбординга — один список `navigation/steps.ts`: стек строится из него,
  общий тест обходит его же, так что новый шаг тоже проверяется.
