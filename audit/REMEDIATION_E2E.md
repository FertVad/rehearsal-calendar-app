# E2E — приложение целиком на симуляторе, и что оно нашло

**Статус: READY_FOR_CHECK.** Ветка `claude/systematic-repair`. Шаг 1 автономной
разработки (решение владельца от 7 октября): Maestro и изолированное окружение.
Находки вне реестра аудита, поэтому нумерация своя — E2E-01…E2E-05.

## Окружение (`466565f`, `b59fbbb`, `dbe8744`)

`npm run e2e` поднимает всё сам и после прогона снимает:
- одноразовую PostgreSQL — локальный образ, tmpfs, 127.0.0.1;
- сервер с окружением, собранным с нуля;
- сид через API;
- свой Metro;
- Debug-сборку на отдельном симуляторе «Rehearsly E2E»;
- сценарии Maestro.

Описание — [docs/e2e.md](../rehearsal-calendar-native/docs/e2e.md).

**Инцидент первых запусков.** Локальный `.env` указывает `EXPO_PUBLIC_API_URL=https://rehearsly.me/api`.
В dev-сборке Expo кладёт `.env` в бандл поверх переменных окружения, поэтому
переменная, переданная Metro, до приложения не доходила. Первая проверка
бандла смотрела только на прелюдию и её пропустила. Приложение запустилось с
боевым адресом. Это заметно по логу Metro (`Using EXPO_PUBLIC_API_URL: https://rehearsly.me/api`).
Ни один сценарий не дошёл до входа. Без сессии приложение запросов не делает:
`loadUser` выходит без токена, регистрация push и синхронизация пояса — только
после входа. Это по коду; сетевого перехвата не было.

Исправлено тремя слоями:
1. `REHEARSLY_E2E=1` убирает корневые `.env*` из бандла (`metro.config.js`).
2. Бандл отвергается, если в нём есть модуль `.env` или любое иное значение
   адреса. Проверено на сохранённом плохом бандле.
3. Адрес, который приложение сообщает при старте, отслеживается; иной
   закрывает приложение и снимает окружение.

После исправления во всех прогонах приложение сообщало только `http://localhost:3001/api`.

| E2E-01 | Шесть шторок — выбор проекта в форме репетиции, пояс в форме проекта, управление участником, выбор периода, «+» на Android, `PickerModal` — iOS отдаёт как одну кнопку. | E2E-02 | 22 кнопки из одной иконки без подписи: «назад», «закрыть», удалить/изменить на карточке, «+», глаз «просмотрено». VoiceOver молчит | Подписи из `common`; у глаза ещё состояние и счёт, новая строка `rehearsals.markSeen` на четырёх языках |
| E2E-03 | «Создать» в форме нового проекта при открытой клавиатуре только прячет её | У ScrollView не было `keyboardShouldPersistTaps`, в отличие от остальных форм |

| E2E-05 | Jest на этой машине (Иерусалим) и в UTC CI не может поймать E2E-04: ошибка видна только западнее UTC. Один тест сам её делал (`minDate` в `DateRangePicker.test`) | Jest закреплён в `America/New_York` (`jest.config.js`); тест исправлен |
