## Результат сверки

- **CreateProjectScreen:** имя trim-проверяется до отправки (`:44–48`), создаваемые поля захвачены одним вызовом createProject (`:52–56`), Create disabled при creating (`:150`), исключение отображается через Alert (`:67–70`). Серверная частичная фиксация project+owner уже B02, account-switch состояние ProjectContext уже BC01 — здесь не дублируются. Back/Cancel и поля остаются доступны во время pending create (`:82,:98,:111,:123,:137–140`); завершившийся Promise затем выполняет navigation (`:60–66`). Это ограничение поведения при уходе во время сохранения, без утверждения, что отмена UI отменяет уже отправленный серверный write. При доработке жизненного цикла форм следует запретить конфликтующие действия или игнорировать позднюю навигацию после ухода; отдельный существенный ID в этом проходе не начислен.
