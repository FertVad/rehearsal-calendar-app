# Подготовка следующего этапа FM01/FM02 — НЕ ВНЕДРЕНО

Архив подготовленных 19 сентября 2026 материалов, сохранённый перед остановкой
по просьбе Вадима из-за лимитов. Эти файлы не подключены к приложению, штатному
мигратору, manifest, CI или обычному тестовому запуску. FM01/FM02 не закрыты.

`design/` описывает предлагаемые профили. `proof/` — неизменённая копия
временного экспериментального пакета с before/after логами, точными SQL,
тестами, командами и хешами. Вложенный README описывает состояние на момент
временного прогона; его утверждение о tmp относится к тому запуску. Внутренние
пути команд сохранены как исторические, не как инструкция запуска из архива.
Симлинки зависимостей и временные БД не копировались.

Фактические проверки черновика: before exit1 (UTC control PASS, четыре
ожидаемых FAIL), after exit0 (26 PASS). Это проверка draft helper и его fixtures,
не штатного migration runner или полной схемы/HTTP приложения.

При продолжении сначала прочитать актуальный реестр и modern R2 отчёт.
Сохранить immutable v1 artifacts; добавить отдельные версии профилей/переходов,
интеграцию с настоящим journal, dry и HTTP, затем независимый review и новые
проверки на source commit. Не применять этот черновик к production.
Отдельно остаются A04/R3 credential lifecycle и R6 semantics времени.
