# Бриф для редизайна лендинга Rehearsly

## Что за приложение

**Rehearsly** — планировщик репетиций для тех, кто собирает много занятых людей в одно
время: театры, балетные труппы, съёмочные группы, продакшены live-шоу.

Задача, которую оно решает, всегда одна и та же. Постановщику нужно назначить репетицию
на восемь человек. У каждого свои спектакли, съёмки, преподавание, другие проекты.
Сегодня это делают в общем чате: «кто когда может?» — и дальше двадцать сообщений,
таблица в заметках и всё равно кто-то не пришёл.

В Rehearsly каждый участник отмечает свою занятость. Приложение само считает пересечения
и показывает окна, когда свободны все — или почти все, с именами тех, кто занят.
Постановщик выбирает окно, создаёт репетицию, она уходит в календари участников на
телефоны. Видно, кто её уже увидел.

**Кто платит за это вниманием:** режиссёры, хореографы, ассистенты, продюсеры,
директора площадок. Люди с профессиональной привычкой к инструментам, а не подростки.
Это рабочий инструмент, а не «ещё один календарик».

**Что важно донести на лендинге, в порядке убывания:**

1. Умный подбор времени по занятости всей команды — это ядро продукта
2. Мышление проектами: одновременно идут «Гамлет», «Лебединое озеро», съёмка клипа и
   прямой эфир премии, и это нормально
3. Синхронизация с календарём телефона — репетиции попадают в Apple Calendar и Google
4. Приглашение в проект одной ссылкой, без регистрации по почте и ручного ввода
5. Четыре языка: русский, английский, испанский, немецкий

## Что не так с текущим дизайном

Первая версия рабочая, но читается как аккуратный шаблон. Не хватает двух вещей.

**Премиальности.** Сейчас это плоские секции одна под другой. Нужны глубина и вес:
слои, мягкие тени, стеклянные поверхности, крупная типографика с сильным контрастом
между заголовком и текстом, воздух между блоками. Ощущение инструмента, за который
платят, а не бесплатного шаблона. Ориентир по уровню — лендинги Linear, Raycast, Arc:
тёмные, спокойные, с одним акцентным цветом и очень выверенной сеткой.

**Движения.** Страница сейчас статична. Нужны появление блоков по мере скролла,
лёгкий параллакс, и главное — прокрутка внутри экранов телефона (см. ниже).

Чего не нужно: стоковых иллюстраций, каруселей с логотипами, градиентных клякс,
эмодзи в заголовках, анимации ради анимации.

## Палитра — берётся из самого приложения

Скриншоты сняты в тёмной теме, и лендинг должен сидеть на тех же цветах, чтобы
макеты телефонов не выглядели вставками из другого продукта.

| Роль | Значение |
|------|----------|
| Фон основной | `#0d1117` |
| Фон секций | `#161b22` |
| Фон приподнятый | `#21262d` |
| Текст основной | `#e6edf3` |
| Текст вторичный | `#8b949e` |
| Акцент | `#A855F7` |
| Акцент тёмный | `#9333EA` |
| Стекло | `rgba(22, 27, 34, 0.7)` + рамка `rgba(139, 148, 158, 0.2)` |

Смысловые цвета статусов — их стоит переиспользовать в блоке про подбор времени:
свободны все `#10b981`, часть занята `#f59e0b`, заняты все `#ef4444`.

## Главное: прокрутка внутри телефона

Часть экранов снята **парами и тройками с перекрытием** — соседние кадры содержат
общий кусок контента. Это сделано специально: их нужно склеить в одно длинное
изображение и анимировать прокрутку внутри рамки телефона, когда блок попадает
в зону видимости.

**Что с чем склеивать и по какому месту:**

- `01` + `01b` — по блоку «Upcoming Events» с карточкой Hamlet
- `04` + `04b` — по списку участников
- `05` + `05b` + `05c` — по слоту «19:00–22:00 Busy: Alex Moreau», затем по заголовку «Tue, Aug 25»
- `07` + `07b` — по блоку «Members»
- `09` + `09b` — второй кадр это модальное окно поверх первого, склейка не нужна
- `10` + `10b` — по блоку «Settings»

Одиночные, прокрутка не нужна: `02`, `03`, `06`, `08`.

Как это должно ощущаться: телефон стоит на месте, содержимое внутри экрана мягко
едет вверх по мере скролла страницы, с замедлением в конце. Не рывками по кадрам,
а непрерывно. Скорость — примерно вдвое медленнее, чем скроллится сама страница,
чтобы движение читалось как отдельный слой.

Пара оговорок по материалу:

- у `07b` внизу красная кнопка «Delete Project» — обрежьте её, заканчивать прокрутку
  на деструктивном действии не стоит
- на `09` две трети экрана пустые, это честное состояние экрана; если мешает —
  используйте только верхнюю часть
- строку статуса (время, wi-fi, батарея) можно оставить или заменить на нейтральную,
  как удобнее макету

## Технические рамки

- Лендинг лежит в `server/public/` и отдаётся тем же Express-сервером, что и API.
  Это не прихоть: файл `apple-app-site-association` обязан жить на том же домене,
  что и ссылки-приглашения, иначе они не будут открывать приложение.
- Чистые HTML/CSS/JS без сборки. Сейчас используются AOS для появления по скроллу
  и Lucide для иконок.
- Домен `rehearsly.me`. Страницы: `/`, `/privacy`, `/support`.
- Языки лендинга: английский и русский, обе версии в разметке, переключатель на JS —
  страница должна оставаться читаемой без JavaScript.
- Приложение выходит в App Store, ссылка на него появится позже — заложите место
  под бейдж «Download on the App Store».
